# 🎰 슬롯머신 5×3 개편 설계 (v0.2.17)

## 규칙
- 5릴 × 3행, 페이라인 20개(`SLOT_PAYLINES`). 활성 라인은 1번부터 N개 — **총 베팅 = 라인 베팅 × 라인 수**.
- 라인 베팅 단계: 1 / 5 / 10 / 50 / 100 / 500 / 1,000 / 5,000 / 10,000 🪙 (`SLOT_BET_TIERS`). 최소 1🪙(1라인), 최대 200,000🪙(20라인).
- 활성 라인마다 1릴부터 **연속** 같은 심볼 3개 이상이면 배당(× 라인 베팅). 🃏 와일드(2~4릴)는 7️⃣·🎁를 제외한 심볼을 대체.
- 🎁 스캐터: 라인과 무관하게 화면 어디든 3/4/5개 → **파츠 1/2/3개**. 파츠를 다 모았으면(미보유 0) 대신 총 베팅 × 1/5/25를 **💎 환산** 지급.
- 💎 라인 배당·💎 환산 보상은 **1,000🪙당 💎 1개**(`SLOT_GEM_RATE`), 나머지는 🪙로.
- 7️⃣ 5개 라인 = **누적 잭팟**. 라인 베팅 100🪙 이상 전액, 그 아래는 비례(10🪙 → 10%). 당첨 후 적립금은 기본 5,000,000🪙으로 복귀(그 아래로 내려가지 않음).

## 누적 잭팟 경제
- 기본 적립금 `SLOT_JACKPOT_BASE` = 5,000,000🪙. 서버 전체 공용, `slot.json`(볼륨)에 영속.
- **서버 전체 골드 소비 전액**(`SLOT_JACKPOT_FEED_PCT` = 100)이 적립: 슬롯 판돈, 상점 구매, 랜덤 뽑기, 낚싯대 강화, 그림 쪽지, 전광판 광고, 펫 먹이. (골드↔젬 환전·주식 매수는 자산 교환이라 제외.)
- 💎 소비도 🪙 환산 뒤 전액 적립: 펫 뽑기 1회 = **5,000🪙**(`SLOT_JACKPOT_PET_PULL_GOLD`, 10연 50,000🪙, 금요일 할인이어도 회수 기준), 원정 강화 💎 1개 = **500🪙**(`SLOT_JACKPOT_BATTLE_GEM_GOLD`).
- 시뮬레이션(20라인): 라인 환급 ≈ 80%, 적중률 ≈ 46%, 🎁 3개+ ≈ 4%/스핀. 파츠를 다 모은 플레이어는 💎 환산 스캐터가 +8%. 판돈 전액이 잭팟으로 돌아오므로 슬롯 전체로는 장기적으로 투입보다 많이 돌려주는 구조(대부분은 잭팟 당첨자 몫).
- 7️⃣×5 확률: 라인당 1/929,800, 20라인 스핀당 ≈ 1/46,490 (하루 300스핀 기준 다섯 달에 한 번꼴).

## 결과 종류(`SlotKind`) / 알림 / 업적
- `jackpot` > `big`(총 베팅 ×30 이상) > `gem`(💎 지급) > `part` > `win` > `miss`. `miss`·`win` 외에는 `slot-win` 전체 알림(채팅 시스템 메시지 + 오버레이 말풍선).
- 잭팟은 전광판 뉴스에도 실리고, 본인 채팅에도 남긴다. `slot-pool` 이벤트로 잭팟 금액을 접속 시 + 변동 시(0.5초 묶음) 전체 전송.
- 업적: `c-jackpot` = 5개 일치 라인, `c-mega`(칭호 도박왕) = 누적 잭팟, `h-broke` = 코인 0으로 시도, `c-slot100`/`c-missrun` 유지.
- 🐾 펫 효과 유지: `slotFree`(무료 스핀 — 판돈 0, 잭팟 적립 없음), `slotRetry`(라인·스캐터 모두 꽝일 때 1회 재굴림), `slotWin`(라인 배당·💎 환산 보상 +%).

## 프로토콜
- `slot({ bet, lines, partsLeft }, ack)` — `partsLeft`는 클라이언트(메인 프로세스)가 세는 미보유 파츠 수. 응답 `SlotResult`: `grid[릴][행]`, `wins[]`(line/symbol/count/pay), `scatter`, `parts`, `coinsWon`, `gemsWon`, `jackpot`, `five`, `coins`, `gems`, `pool`, `free`.
- 파츠 지급은 기존대로 클라이언트 로컬(`grantRandomPart` × parts) → `partLabels`.
- 구버전 클라(v0.2.16 이하, ack 1인자)는 서버가 업데이트 안내 오류로 응답.
- 검증 전용 훅: `DOTCHAT_SLOT_RIG=1`로 띄운 서버만 요청의 `rig`(5×3 그리드)를 그대로 사용.

## 검증
- `node tools/verify-slot.mjs` — 테이블 동기화(shared ↔ composer.ts 복사본), 규칙 시뮬레이션 범위, 프로토콜(입력 검증·연타·잔액 부족·무작위 스핀 정산 재계산·잭팟 적립·강제 그리드로 와일드/💎/🎁/잭팟 전액·비례/업적/통지). 시드 지갑(코인 1억, 슬롯검증#0077)으로 `DOTCHAT_SLOT_RIG=1` 서버 필요.
- `node tools/slot-harness.mjs && node tools/serve.mjs` → `http://localhost:5317/tools/slot-harness.html?panel=slot` — 패널 UI(다중 라인 당첨·꽝·💎 환산·잭팟·오류 시나리오 순환).
