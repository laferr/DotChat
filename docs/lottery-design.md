# 🎟️ 즉석복권 설계 (v0.2.17)

## 규칙
- 한 장 2,000🪙(`LOTTO_PRICE`). 구매 즉시 서버가 판정하되 **미공개 티켓**으로 보관하고, 클라이언트에서 은박을 긁어 공개하면 `lottery-claim`으로 당첨금을 지급한다(1원 = 1🪙).
- 은박(캔버스)을 **80% 이상** 긁거나 **자동긁기** 버튼을 누르면 남은 은박이 위에서 아래로 자동으로 긁히며 결과(당첨/꽝 + 당첨금)가 드러난다.
- 화면 문구는 **"최대당첨금 10억원!"** 만 표시하고 확률은 표기하지 않는다.
- 긁지 않은 채 창을 닫아도 티켓은 서버에 남는다. 다시 열면 그대로 긁을 수 있고, 긁지 않고 새로 사면 이전 티켓을 먼저 자동 정산한다(당첨금 유실 없음).
- 복권 판돈도 서버 골드 소비이므로 전액 🎰 누적 잭팟에 적립된다.

## 당첨 표 (첨부 표의 당첨금·확률만 반영, 매수는 무시)
| 등수 | 당첨금 | 확률 |
| --- | --- | --- |
| 1등 | 1,000,000,000 | 1/5,000,000 |
| 2등 | 100,000,000 | 1/1,666,667 |
| 3등 | 10,000,000 | 1/200,000 |
| 4등 | 20,000 | 1/363.6 |
| 5등 | 4,000 | 1/14.3 |
| 6등 | 2,000 | 1/3.6 |

- 구현은 3천만 분모(`LOTTO_POOL`)의 가중치 [6, 18, 150, 82,500, 2,100,000, 8,400,000] — 나머지 ≈ 64.7%는 꽝.
- 이론 환급률 ≈ 60% (장당 기대 1,200🪙). 6등 ≈ 28%, 5등 ≈ 7%, 4등 ≈ 0.28%.

## 알림 / 업적
- 3등 이상(`LOTTO_NEWS_RANK`)은 `lottery-news` 전체 알림(채팅 시스템 메시지 + 오버레이 말풍선), 2등 이상은 전광판 뉴스.
- 업적: `c-lotto50`(즉석복권 50장, stat `lottoTickets`), `c-lotto-big`(3등 이상, 칭호 **벼락부자**). 코인 0으로 시도하면 `h-broke`.

## 프로토콜
- `lottery-state(ack)` → `{ ticket | null, coins }`
- `lottery-buy({}, ack)` → `LottoResult { ticket: { id, rank, prize, ts }, coins }` (rank 0 = 꽝). 검증 서버(`DOTCHAT_SLOT_RIG=1`)만 `{ rig: 등수 }`로 강제.
- `lottery-claim(ticketId, ack)` → `{ rank, prize, coins }`; id가 다르거나 티켓이 없으면 거부.
- 지갑 `wallet.lottery`에 미공개 티켓 보관. 클라 IPC: `lotteryState / lotteryBuy / lotteryClaim`, 팝아웃 `lottery` 340×470.

## 클라이언트 긁기
- `#lotto-card` 아래층에 결과 텍스트, 위층 `<canvas id="lotto-foil">`에 은박(그라데이션 + 잡티 + "여기를 긁어보세요"). 포인터 드래그마다 `destination-out` 원 붓질(반지름 14, 5px 간격 보간).
- 6번 이동마다 알파 샘플링(5px 간격)으로 지워진 비율을 계산해 `#lotto-pct`에 표시, 80% 이상이면 자동 공개.
- 자동 공개 연출: 0.7초 동안 위→아래 지그재그 붓질 후 은박 페이드 → claim → 결과 문구·카드 글로우(3등 이상은 깜빡임).

## 검증
- `node tools/verify-lottery.mjs` — 테이블/복사본 동기화, 판정 시뮬레이션(환급·빈도), 프로토콜(잔액 부족·구매·적립·상태·claim 거부/지급/중복·연타·자동 정산·강제 1등 통지/업적·꽝). 시드 지갑(코인 1억, 슬롯검증#0077)으로 `DOTCHAT_SLOT_RIG=1` 서버 필요.
- `node tools/lottery-harness.mjs && node tools/serve.mjs` → `http://localhost:5317/tools/lottery-harness.html?panel=lottery` — 긁기 UI(4등 → 꽝 → 1등 → 잔액 부족 순환).
